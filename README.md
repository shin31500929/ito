# ito - AI Discord Bot

itoは、優しく癒やし系の人格を持ち、ユーザーとの会話の文脈に応じて自然な愛情表現や共感を返すAI搭載型Discord Botです。

単純なメッセージ応答ではなく、ユーザーの発言意図や会話履歴を考慮したコミュニケーションを目指しています。

### Features
- AIによる自然な会話生成
- 会話履歴を利用した文脈理解
- 愛情表現・愛情要求・通常発言の意図分類
- 優しく癒やし系の人格設定
- 指定Discordチャンネルのみでの動作

### Tech Stack
- TypeScript
- Node.js
- discord.js
- OpenAI Responses API
- Git / GitHub
